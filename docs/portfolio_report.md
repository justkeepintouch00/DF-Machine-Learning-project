## 2. 분류: 당뇨병 위험군 탐지

### 문제와 지표

데이터의 양성 비율이 낮아 Accuracy만 사용하면 당뇨 환자를 정상으로 분류하는 FN이 많아질 수 있다. 따라서 `실제 양성 탐지율(Recall)`과 Recall에 두 배 가중치를 둔 `F2`를 모델 선택 지표로 사용했다. Precision·Specificity·PR-AUC도 함께 기록해 오탐 비용을 숨기지 않았다.

### 검증 설계

- 253,680행을 계층 분할: 훈련 60%, 검증 20%, 테스트 20%
- 임계값: 검증 F2 최대값으로 선택
- 테스트: 최종 보고에만 사용
- 다수 클래스 중복 제거: 훈련 세트에서만 수행
- IQR 행 삭제: 건강 일수와 BMI를 통계적 이상치라는 이유만으로 삭제하면 고위험 환자를 제거할 수 있어 최종 재현 실험에서는 사용하지 않음

### 결과

| 지표 | RF 기본(0.5) | Logistic+LightGBM 앙상블(0.425) | 변화 |
|---|---:|---:|---:|
| Accuracy | 0.8655 | 0.6784 | -18.71%p |
| Precision | 0.5643 | 0.2814 | -28.29%p |
| Recall | 0.1508 | 0.8421 | +69.13%p |
| F1 | 0.2380 | 0.4219 | +18.39%p |
| F2 | 0.1767 | 0.6022 | +42.55%p |
| ROC-AUC | 0.8157 | 0.8265 | +1.09%p |
| PR-AUC | 0.4094 | 0.4241 | +1.46%p |
| FN | 6,003 | 1,116 | -4,887(-81.41%) |
| FP | 823 | 15,201 | +14,378 |

- 테스트 F2 개선폭의 부트스트랩 95% CI: **+0.4137~+0.4358**
- 학습시간: 1.921초→3.806초(98.12% 증가)
- 1,000건 추론시간: 2.131ms→1.576ms(26.06% 감소)

### 결론

FN을 줄이는 목적에는 앙상블이 적합하지만 FP가 크게 늘었다. 따라서 “성능이 전반적으로 좋아졌다”가 아니라, **검진 누락 비용을 오탐 비용보다 크게 둔 정책에서 FN을 81.41% 줄였다**고 표현해야 한다. 실제 운영 전에는 하루 검진 가능 인원과 FN/FP 단가를 받아 임계값을 다시 산정해야 한다.

## 3. 회귀: 주문별 판매금액 예측

### 미완료 과제와 수정

강사 조언은 비선형 트리 모델에서 낮은 선형 상관계수만으로 변수를 버리지 말고, 이상치를 일괄 삭제하지 말며 유지/제거 결과를 비교하라는 것이었다. 기존 노트북은 전체 100,000행에서 IQR 이상치 1,415행을 먼저 제거했지만 비교 실험이 없었다.

이번 재현 실험에서는 날짜순으로 훈련 70,000행, 검증 15,000행, 테스트 15,000행을 분할했다. 훈련 종료일은 2025-05-26, 검증 종료일은 2025-09-12, 테스트 종료일은 2025-12-30이다. 이상치 제거 변형은 훈련 데이터의 1,024행만 제외했고 검증·테스트는 그대로 유지했다.

### 결과

| 모델/변형 | 검증 RMSE | 테스트 MAE | 테스트 RMSE | 테스트 R² |
|---|---:|---:|---:|---:|
| Linear 유지 | 0.9768 | 0.8316 | 0.9784 | 0.9684 |
| XGBoost 유지 | 0.9217 | 0.8007 | 0.9280 | 0.9715 |
| XGB+LGBM 유지 | **0.9216** | 0.8013 | 0.9287 | 0.9715 |
| XGBoost 훈련 이상치 제거 | 0.9993 | 0.8262 | 0.9975 | 0.9671 |
| XGB+LGBM 훈련 이상치 제거 | 1.0033 | 0.8275 | 1.0010 | 0.9669 |

### 선택 논리

- 앙상블의 검증 RMSE는 XGBoost보다 0.0108% 낮을 뿐이다.
- 이번 재실행에서 측정된 앙상블 추론시간은 XGBoost보다 약 4.11배 길었다.
- 따라서 `최저 검증 RMSE의 0.1% 이내 후보 중 추론시간 최소` 규칙으로 **이상치 유지 XGBoost**를 선택했다.
- Linear 대비 XGBoost: MAE 3.71% 감소, RMSE 5.16% 감소, R² +0.318%p.
- RMSE 감소량 부트스트랩 95% CI: **0.0458~0.0556**.
- XGBoost 유지 모델은 XGBoost 이상치 제거 모델보다 테스트 RMSE가 **6.97% 낮았다**.

### 결론

이 데이터에서는 고액 주문이 오류가 아니라 예측해야 할 정상 업무 범위였다. 강사의 조언대로 이상치를 유지하는 것이 검증·테스트 모두 더 좋았다. 다만 데이터가 합성 데이터이므로 이 수치를 실제 매출 일반화 성능으로 주장해서는 안 된다.

## 4. 비지도학습: 신용카드 고객 세분화

### 목표와 검증 방식

비지도학습의 목표는 정답 정확도가 아니라 재현 가능하고 설명 가능한 고객군을 도출하는 것이다. 원본 8,950명, 군집 입력 17개 변수를 사용했으며 결측치는 중앙값으로 대체했다.

`raw+StandardScaler`, `log1p+StandardScaler`, `log1p+RobustScaler`, `log1p+StandardScaler+PCA95%`를 k=2~8에서 비교했다. 운영 캠페인 3종이라는 요구를 k=3으로 변환하고, k=3 후보 중 내부 지표가 가장 좋은 전처리를 선택했다.

### 결과

| 지표 | 기존 raw+Standard k=3 | 선택 log1p+Robust k=3 | 변화 |
|---|---:|---:|---:|
| Silhouette | 0.2455 | 0.3916 | +0.1461, +59.49% |
| Calinski-Harabasz | 1,605.09 | 3,511.26 | +118.76% |
| Davies-Bouldin | 1.5968 | 1.0622 | 33.48% 감소(낮을수록 좋음) |

- 5개 시드 쌍별 안정성: 평균 ARI 0.9989, 최소 ARI 0.9982
- PCA 17→10차원, 설명분산 95.89%; PCA 전후 군집 ARI 0.9983
- KMeans와 GMM k=3 ARI: -0.0351
- GMM BIC 선택 k: 6, 그러나 k=3 Silhouette 0.0784로 KMeans보다 낮음

### 비즈니스 그룹

1. **고구매·쇼핑/VIP 후보군** — 1,307명(14.60%): 평균 구매액 1,927.21, 구매빈도 0.813, 완납비율 0.788. 프리미엄 혜택·교차판매 가설.
2. **현금서비스 의존 후보군** — 6,403명(71.54%): 평균 잔액 2,113.43, 현금서비스 1,247.73, 완납비율 0.033. 분할상환 전환·금융건전성 안내 가설.
3. **저활동·재활성화 후보군** — 1,240명(13.85%): 평균 잔액 168.71, 구매액 339.01, 구매빈도 0.278. 저비용 재활성화 가설.

이 그룹명과 액션은 관찰 데이터 기반 가설이다. 실제 캠페인 uplift나 수익 향상은 현재 데이터에 없으므로 성과라고 주장할 수 없다.

## 5. 비선택 실험을 남긴 방식

원본 실험 셀과 출력은 각 노트북의 앞부분에 그대로 유지했다. 추가 재현 실험은 맨 아래에 구분했고, 각 `results` 폴더의 모델 비교표에도 실패·비선택 실험을 남겨 의사결정 근거를 확인할 수 있게 했다.

- 분류: Accuracy 최적화가 Recall을 악화시키는 사례
- 회귀: 이상치 제거와 복잡한 앙상블이 반드시 유리하지 않은 사례
- 비지도: GMM의 높은 소속확률이 정확도가 아니며, 다른 목적함수는 다른 군집을 만든다는 사례

포트폴리오 본문에는 최종 비교표와 선택 이유를 제시하고, 상세 수치는 `classification/results`, `regression/results`, `unsupervised/results`로 연결한다.
